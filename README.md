## About Me

I’m an **aspiring analyst** focused on **Big Data Analytics**. I enjoy converting raw data into **decision-ready insights** through **KPI development, reporting, dashboards, and structured analysis** using **SQL, Excel, Power BI, and Python**.

My goal: **make data useful for decisions** (what’s happening, why it’s happening, and what to do next).

### Core Strengths

- **SQL Analytics** – joins, aggregations, CTEs, reusable queries  
- **Excel Analysis** – dashboards, validation, dynamic formulas  
- **Power BI Dashboards** – clean visuals + stakeholder-ready reporting  
- **Data Cleaning + EDA** – structured analysis with reproducible workflow
